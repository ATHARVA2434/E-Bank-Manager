# E Bank Manager - Bank Comparison Web Platform

**E Bank Manager** is a responsive web template designed to help users compare various banks on services, interest rates, and policies. Built with the Bootstrap 5 framework, this project aims to make banking decisions easier and more informed for users.

## 📌 Features

- 🔎 **Compare 100+ Banks**: Includes interest rates, policies, and available services.
- 💳 **Loan & FD Comparison**: Quickly find the best deals for loans and fixed deposits.
- 📱 **Responsive Design**: Mobile-friendly layout using Bootstrap v5.
- 📞 **Direct Contact Options**: Users can reach out to banks directly or via a built-in contact form.
- 🌐 **Interactive UI**: Sections for services, team members, portfolios, and contact info.
- 🧩 **Modular Pages**: Includes main index, inner pages, and portfolio detail views.
